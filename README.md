## 🧩 Supported Asset Types

Source2PortTools is built around the asset types that matter most in game porting. Each type has its own role in a project.

### 🧊 Models

Models are the 3D objects in a game. They can be characters, weapons, furniture, tools, machines, or environment pieces. When you port a model, you are preparing that object so it can appear in a Source 2 project. Source2PortTools helps move model content from the older Source 1 format toward the newer Source 2 format.

For a non-technical user, the important part is that a model is more than a shape. It can have parts that move, attachment points, and other details. The porting tool helps manage the conversion so you do not have to handle every detail by hand.

### 🖼️ Textures

Textures are the images that cover models and surfaces. They add color, wear, detail, and realism. A metal wall, a wooden crate, a character face, and a painted sign all rely on textures.

Source2PortTools helps prepare texture files for Source 2 use. This is useful when you want the look of a Source 1 asset to carry over into Half-Life: Alyx or S2FM. Textures often work together with materials, so keeping both in the same workflow saves time.

### 🎨 Materials

Materials control how a surface behaves visually. They can affect color, shine, transparency, and other surface properties. In Source projects, material files are often linked to textures and models.

Source2PortTools supports material conversion as part of the porting process. That means you can move the visual setup of an asset along with its model and texture files. For users who are new to modding, this is one of the most helpful parts of the tool because material files can be confusing when handled separately.

### ✨ Particles

Particles are the small visual effects that make a scene feel alive. They are used for smoke, fire, sparks, dust, rain, snow, magic effects, explosions, and ambient details. Particle files can be tricky because they combine timing, appearance, and motion.

Source2PortTools includes particle support so those effects can be part of the same porting workflow. This helps when you want to bring over an effect from Source 1 and use it in a Source 2 scene.

After the process finishes, move the finished files into your Half-Life: Alyx or S2FM project. Keep the folder structure tidy. Use clear names. If you are testing a new asset, place it in a small test project first so you can check how it looks before adding it to a larger scene.

## 🛠️ Tips for a Smooth First Port

- Start with one asset, not a whole folder. A single model or texture is easier to check.
- Keep your Source 1 files in a dedicated folder before you begin.
- Keep related files together. Models, textures, and materials often depend on each other.
- Use short, clear folder names with no strange symbols.
- Test the converted asset in a small Half-Life: Alyx or S2FM project first.
- If an asset looks wrong, check that all its related files were included in the port.
- Avoid renaming files after conversion unless you have a specific reason.
- Work in small batches so you can spot problems early.

These habits make porting easier to manage. They also help you learn how Source2PortTools handles different asset types without turning your first project into a large cleanup job.
